## 🛍️ می‌خواهید قالب خام را بگیرید؟

اگر می‌خواهید نسخهٔ خام و قابل‌شخصی‌سازی را برای خودتان داشته باشید، به مخزن قالب بروید:

**📦 [دریافت قالب خام](https://github.com/FictaLand/Resume-Template)**

یا مستقیماً روی دکمهٔ **Use this template** کلیک کنید تا نسخهٔ خودتان را بسازید.

> 💡 نسخهٔ منتشرشدهٔ قالب در حال حاضر **v1.6.0** است؛ دمو همیشه جدیدترین نسخه را نشان می‌دهد و قالب به‌زودی همگام‌سازی می‌شود.
