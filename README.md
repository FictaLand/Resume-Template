# 🪐 قالب رزومهٔ تعاملی «مدار» — Orbit Resume Template

یک قالب رزومهٔ **تک‌فایله، تعاملی و راست‌چین (فارسی)** بدون هیچ کتابخانه و وابستگی خارجی.
فقط فایل `index.html` را باز کنید؛ رزومهٔ شما آمادهٔ نمایش، خروجی PDF و ارسال در پیام‌رسان‌هاست.

---

## ✨ امکانات

- 🌗 حالت روشن / تاریک
- 🌀 انیمیشن مداری با کنترل سرعت و توقف حرکت
- 📄 خروجی PDF با یک کلیک (از طریق چاپ مرورگر)
- 🖼️ خروجی PNG آمادهٔ ارسال در پیام‌رسان‌ها
- 📱 واکنش‌گرا (موبایل و دسکتاپ)
- 🇮🇷 کاملاً فارسی و راست‌چین
- 📦 بدون وابستگی — فقط یک فایل HTML

---

## 🚀 شروع سریع

### روش ۱: استفاده از قالب (پیشنهادی)
روی دکمهٔ سبز **Use this template** بالای صفحه کلیک کنید → **Create a new repository** → نسخهٔ خودتان را بسازید.

### روش ۲: Fork کردن
روی دکمهٔ **Fork** کلیک کنید تا یک کپی از مخزن در حساب خودتان ساخته شود.

### روش ۳: دانلود مستقیم
فایل `index.html` را دانلود کنید و روی سیستم خودتان باز کنید.

---

## ⚙️ شخصی‌سازی

فایل `index.html` را در یک ویرایشگر متن (مثل VS Code) باز کنید و این موارد را جایگزین کنید:

1. نام و عنوان شغلی
2. اطلاعات تماس (تلفن، ایمیل، لینکدین)
3. متن «خلاصه حرفه‌ای»
4. بخش‌های مهارت‌ها، سوابق شغلی، تحصیلات و گواهی‌ها
